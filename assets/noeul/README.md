# Noeul icon

Noeul (노을, the evening glow): a striped setting sun over a horizon, with its reflection. Same 40-unit tile as Subak's (`assets/subak/subak.svg`: `#1C1B24`, radius 9.5, a 1-unit
`#26252F` edge), one flat glyph, readable from 16 px ([ADR 0090](../../docs/adr/0090-kim-minimal-launcher.md)).

| File | Use |
| --- | --- |
| `noeul.ico` | Windows, 16–256 px (9 sizes), PNG entries; linked into the noeul programs by `crates/kim-winres` |
| `noeul-{16,20,24,32,48,64,128,256}.png` | PNG sizes (Kim Manager's launcher uses the 256 px one) |

Generated by `assets/brand/make_tool_icons.py` (developer tool, needs Pillow; not part of any
shipped binary), never by hand:

```sh
python -I assets/brand/make_tool_icons.py
```
