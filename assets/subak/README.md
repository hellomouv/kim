# Subak icon

Subak (수박, watermelon): a slice with a near-black rind and red flesh. Specification, colours,
measured contrast and the motion of the Claude marks: [docs/SUBAK_BRAND.md](../../docs/SUBAK_BRAND.md).

| File | Use |
| --- | --- |
| `subak.svg` | vector master (same geometry and colours as the renderer; checked by a test) |
| `subak.ico` | Windows, 16–256 px, PNG entries |
| `subak-{16,20,24,32,48,64,128,256}.png` | PNG sizes |
| `subak-mono-dark-*.png`, `subak-mono-light-*.png` | monochrome / High Contrast variants |
| `preview-dark.png`, `preview-light.png` | 16–48 px on a near-black and a light surface |

Generated by the run-time renderer (`crates/subak/src/gui/float/art.rs`), never by hand:

```sh
SUBAK_WRITE_ICONS=1 cargo test -p subak --test icon_assets   # regenerate
cargo test -p subak --test icon_assets                       # check (part of cargo xtask ci)
```
